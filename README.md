# Flight Tonight

A responsive flight booking web application that allows users to search destinations and simulate flight booking.

## Technologies Used
- HTML
- CSS
- JavaScript
- REST API

## Features
- Search destinations
- View available flight data
- Booking simulation
- Responsive interface

## What I Learned
- API integration
- Dynamic UI rendering
- Front-end project structure
